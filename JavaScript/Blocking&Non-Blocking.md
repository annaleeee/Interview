## Blocking과 Non-Blocking
** 작업 수행 시 제어권이 누구한테 있는지에 따라 구분
- Blocking
  - 해당 작업이 완료될 때까지 다른 작업 수행 불가
- Non-Blocking
  - 해당 작업이 완료되기 전까지 다른 작업 수행 가능
---
- 동기 / 비동기 + 블로킹 / 논블로킹
  - Sync Blokcing ( 동기 + 블로킹 )
  - Async Blocking ( 비동기 + 블로킹 )
  - Sync Non-Blocking ( 동기 + 논블로킹 )
  - Async Non-Blocking ( 비동기 + 논블로킹 )

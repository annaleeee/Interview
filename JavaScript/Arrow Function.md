## Arrow 함수를 쓰는 이유?
`1) 함수 본연의 기능을 잘 표현한 문법`
 - 함수 본연의 입출력기능을 직관적으로 표현
    - 입출력기능이 쉽고 가독성이 좋게 표현 <br>
    
`2) 소괄호 생략이 가능`
  - 파라미터가 하나일 경우 생략 가능 <br>
  
`3) 중괄호 생략이 가능`
  - return이 한 줄 뿐이라면 중괄호와 return 생략 가능 <br>
  
`4) 내부에서 this값을 쓸 때, 밖에 있던 this값을 그대로 사용이 가능함` 
  - arrow function은 어디서 쓰던 내부의 this값을 변화시키지 않음
  - 밖에 있는 this의 의미를 그대로 내부에서 사용 <br>
    → 이전 this 값 재사용 가능
---
- 화살표 함수는 생성자 함수로 사용 불가능 ( prototype 프로퍼티를 가지고 있지 않기 때문 )

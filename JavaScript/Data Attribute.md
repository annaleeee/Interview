## 데이터 속성 ( Data Attribute )
- 데이터 속성
  - HTML5부터 등장
  - HTML 요소의 `data-` 로 시작하는 속성
  - 브라우저는 이러한 데이터 속성에는 어떠한 행동도 관여하지 않음 <br>
    → 개발자는 요소에 특정한 데이터를 저장하고 싶은 경우 자유롭게 사용 가능
  - 특정한 데이터를 DOM 요소에 저장해두기 위한 목적
  - 하나의 태그에 사용할 수 있는 커스텀 데이터 속성의 개수 제한 X
    - 원하는만큼 커스텀 데이터 속성 추가 가능

#### [ 장점 ]
- 이전과 같이 hidden으로 태그를 숨겨두고 데이터를 저장할 필요 X
  - HTML 코드가 간결해짐
- 하나의 HTML 요소에 여러 데이터 속성을 동시에 사용 가능함
- 자바스크립트를 통한 데이터 접근이 간단해짐

#### [ 단점 ]
- html이 누구에게나 보이고, Javascript로 접근 가능
  - 민감하고 중요한 데이터는 저장 지양
- 인터넷 익스플로러 11 이전 버전들은 dataset 지원 X ( 호환성 문제 )
  - 대신, getAttribute( )을 통하여 데이터 속성에 접근해야 함
